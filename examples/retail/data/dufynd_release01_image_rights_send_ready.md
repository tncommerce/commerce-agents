## Acceptance and follow-up

Do not treat an acknowledgement, customer-service autoresponse, forwarded
ticket or generic media link as permission by itself.

For any positive reply, capture:

- exact product and GTIN;
- exact approved asset URL/file/media identifier;
- authorizing party;
- grant date;
- commercial public web use;
- affiliate/comparison use;
- media;
- territory;
- duration / expiry;
- attribution;
- modification rules;
- revocation/removal conditions;
- source message or licence evidence location.

If the reply is incomplete on a material condition, keep the product at
`licensed_source_required`.

After valid rights evidence is recorded:
1. register the exact asset as a review-only rights-cleared candidate;
2. perform exact bottle / concentration / size visual review;
3. request human/user visual approval;
4. only then approve the image.

No outbound message in this file may be sent without explicit user approval.
