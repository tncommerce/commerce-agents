### Trademark screen — TMview
Result: pass_preliminary

A direct query against TMview's public search endpoint across all participating trademark offices returned:
- exact / contains query DUFYND: 0 results
- prefix-near query DUFYN: 0 results
- phonetic/spelling-near query DUFIND: 18 contains results, but no exact DUFIND mark; returned rows were longer unrelated names such as EDUFIND / EDUFINDER

Conflict classes considered for SCENTAI/DUFYND's likely operating model include Nice 3, 9, 35 and 42 (fragrance goods, software/digital products, commerce/advertising and software/SaaS services).

This is a strong preliminary signal, but not a substitute for an attorney-led phonetic/similarity clearance before filing.
