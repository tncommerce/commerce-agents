## Interruption, repeat and stop

The fixed concurrency group serializes matching jobs; it does not cancel an active
review. There is no automatic retry/scheduler. A partial acquisition produces no
published artifact. Normal exceptions/KeyboardInterrupt clean the temporary raw
feed; the shell EXIT trap and ephemeral runner isolate cleanup on job termination.
SIGKILL/runner outage is not falsely claimed to run Python cleanup.

Encrypted output is flushed/fsynced into a private temporary file, then atomically
linked without overwriting an existing output. Concurrent publication has one
winner. A failed write leaves no final file; restart reacquires a fresh source and
does not resume unverified plaintext. Hard termination may leave temporary bytes
on the ephemeral runner until its teardown; no artifact step runs on failure.
Duplicate authorized reviews may produce distinct evidence envelopes but never
double-register products or offers because this path has no such mutations.

Stop by cancelling the Actions run. Rollback of this development change is simply
not dispatching it or reverting its development commit. No database rollback,
production deploy or Cron change is needed. Nightshift #779 and Cron 11 are untouched.
