# DUFYND visual-world matrix · 25 September 2026

The current 32 editorial fragrance scenes are strong enough to establish a coherent first catalog, but the audit shows that the same Mediterranean/sunset/tabletop language is repeated too often. DUFYND should keep AI imagery as a core brand advantage while separating **product truth** from **editorial attraction**.

The website already derives five atmosphere families from fragrance accords. Future product imagery should use the same families so stills, motion, depth layers and true 3D feel like one system instead of separate experiments.

## Visual families

| DUFYND world | Visual language | Best fit |
| --- | --- | --- |
| **Noir** | black stone, smoked glass, controlled edge light, precision macro, sparse metallic detail | smoky, leathery, resinous, dark woody fragrances |
| **Amber** | warm architectural light, cognac/amber glass, tactile gourmand materials, restrained shadow | sweet, gourmand, creamy, oriental fragrances |
| **Mineral** | pale limestone, brushed metal, cool daylight, water/glass reflections, crisp negative space | fresh, citrus, aquatic, green fragrances |
| **Silk** | soft ivory, fabric/frosted glass, refined floral detail, diffused light | floral, powdery and elegant clean fragrances |
| **Ember** | dark wood, warm copper/brown light, charred/mineral textures, understated spice | woody/spicy fragrances that are neither gourmand nor overtly smoky |

## Product-truth rule

A DUFYND AI image may be more attractive than an official packshot and may become the primary image, but only after it passes the existing fidelity gate. Until then it remains an editorial image and is labelled accordingly on the detail page.

The primary product layer should never be forced to carry every creative purpose. A fragrance can simultaneously have:

1. a reference-faithful primary bottle image;
2. one or more editorial worlds;
3. macro/detail images;
4. a verified transparent cutout;
5. a verified GLB/3D model.

This avoids the current compromise where one campaign-style image must work as catalog thumbnail, product truth, detail hero and social asset at the same time.

## 3D alignment

The still-image system should support the 3D roadmap rather than compete with it:

- primary bottles use centered safe areas and clean silhouette separation;
- editorial backgrounds should be able to sit behind a cutout/model without a second bottle;
- macro assets should focus on real cap/plaque/material details only after fidelity verification;
- exploded views should use verified ingredients/components and must not imply mechanical internals that do not exist;
- true GLB models stay disabled until side-by-side reference QA passes.

The current Naxos depth treatment remains a useful bridge, but the target is a verified product object in a dynamic DUFYND world, not an AI campaign image pretending to be 3D.
