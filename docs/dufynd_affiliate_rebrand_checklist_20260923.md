# DUFYND Affiliate Rebrand Checklist — 2026-09-23

## Goal

Update network-facing publisher metadata from the historical SCENTAI public brand to **DUFYND** without disturbing existing applications, approvals, tracking relationships or account history.

## Awin

When the operator opens Awin:

1. Confirm the publisher account itself remains the existing TNCommerce account.
2. Update the public promotional-site / property name to **DUFYND** wherever editable.
3. Update the promotional website URL to **https://dufynd.de**.
4. Replace any SCENTAI-facing site description with a concise DUFYND description, for example:
   - “DUFYND ist eine deutschsprachige Duft-Discovery- und Vergleichsplattform. Nutzer können Duftprofile entdecken, Alternativen vergleichen und verfügbare Händlerangebote aufrufen.”
5. Do **not** withdraw or re-submit open applications solely because of the rebrand.
6. Verify that **Perfumetrader** still shows as approved afterwards.
7. Verify that Douglas, Flaconi, Breuninger, Birkholz and top Parfümerie remain in their existing open/pending states.
8. Do not change editorial ranking rules or commission-based merchant ordering.

## CJ Affiliate

When the operator opens CJ:

1. Keep the existing TNCommerce publisher account.
2. Update website/property branding to **DUFYND** where editable.
3. Update the website URL to **https://dufynd.de**.
4. Preserve the existing **Notino** application; do not reapply solely for the rebrand.
5. Verify the application status after saving.

## After both networks

Capture one screenshot/status confirmation from each network and update:
- `examples/retail/data/scentai_affiliate_programs.json`
- the DUFYND operator roadmap if any partner state changed.

## Guardrail

A brand/profile update is metadata maintenance, not a reason to alter recommendation logic, merchant ranking or affiliate commission policy.
