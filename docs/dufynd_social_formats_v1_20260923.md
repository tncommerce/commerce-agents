# DUFYND Social Formats v1

Status: active from 2026-09-23
Brand: DUFYND
Operating rule: Social visuals are purpose-built campaign assets. Website product imagery may be used as reference for product truth, but not as the primary visual treatment for social posts.

## Format 1 — I WANT TO SMELL …

**Purpose:** Desire, saves, identity and repeatable series recognition.

**Hook pattern:**  
I WANT TO SMELL + one strong mood word or phrase.

Examples:
- I WANT TO SMELL ADDICTIVE
- I WANT TO SMELL EXPENSIVE
- I WANT TO SMELL CLEAN
- I WANT TO SMELL DANGEROUS
- I WANT TO SMELL DIFFERENT

**Visual language:**  
2–3 real, recognizable fragrances staged inside one coherent campaign world. Each post receives a distinct color/material world appropriate to the mood. No pasted website cards. Product truth remains locked.

**Best use:** Carousel cover, static hero, occasional short.

**Primary KPI:** Saves and shares.

---

## Format 2 — 3 SCENTS FOR …

**Purpose:** Fast recommendation utility without turning the post into dry education.

**Hook pattern:**  
3 SCENTS FOR + situation / identity / mood.

Examples:
- 3 SCENTS FOR DATE NIGHT
- 3 SCENTS FOR THE OFFICE
- 3 SCENTS FOR SUMMER NIGHTS
- 3 SCENTS FOR QUIET LUXURY
- 3 SCENTS FOR COMPLIMENTS

**Visual language:**  
One campaign universe per carousel. Each fragrance gets its own hero slide with custom staging and a short emotional descriptor. Social assets are newly created and must not reuse the website presentation as the final visual.

**Best use:** 4:5 carousel.

**Primary KPI:** Saves, comments and profile visits.

---

## Format 3 — SMELLS MORE EXPENSIVE THAN IT IS

**Purpose:** Value discovery with a strong sales hook.

**Hook pattern:**  
3 FRAGRANCES THAT SMELL MORE EXPENSIVE THAN THEY ARE.

Possible variants:
- SMELLS LIKE €200
- LUXURY WITHOUT THE LUXURY PRICE
- UNDER €50, DOESN'T SMELL LIKE IT

**Visual language:**  
Dark luxury product campaign photography, high-end materials, premium lighting, strong composition. Avoid cheap "budget" visual cues. The point is to make the fragrance feel aspirational first; price/value context comes second.

**Best use:** Carousel; optional viral short once the format proves itself.

**Primary KPI:** Saves, click intent and comments.

---

## Format 4 — IF YOU LIKE X, TRY …

**Purpose:** DUFYND discovery/comparison value in a social-native format.

**Hook pattern:**  
IF YOU LIKE [KNOWN FRAGRANCE], TRY THESE.

Examples:
- IF YOU LIKE NAXOS, TRY THESE
- IF YOU LIKE IMAGINATION, TRY THESE
- IF YOU LIKE LAYTON, TRY THESE

**Visual language:**  
Original fragrance establishes the world on slide 1. Alternatives receive independent campaign scenes that share enough art direction to feel related but never like copies. Relationship claims must follow verified DUFYND data.

**Best use:** Carousel first; short only when a strong viral reference structure exists.

**Primary KPI:** Saves, comparison engagement and DUFYND landing sessions.

---

## Format 5 — CINEMATIC FRAGRANCE FILM

**Purpose:** Reach, brand desirability and premium perception.

**Hook:**  
Visual-first. The first 1–2 seconds must stop the scroll without requiring explanatory text.

**Visual language:**  
Real fragrance, locked product truth, director/DP shot design, exact lens/camera/movement/light/material instructions, fashion-film pacing, trend audio from the platform, sparse physically motivated Foley only.

Reference standard:
- Naxos final = minimum quality floor
- Example-led recreation is allowed as cinematic grammar, but the fragrance palette, product truth and world must be re-authored for the selected product.

**Best use:** TikTok, Instagram Reels, YouTube Shorts.

**Primary KPI:** Reach, completion rate, replays, profile visits and downstream DUFYND sessions.

---

## Cadence

Preferred 4-day loop:
1. Viral cinematic short
2. Carousel derived from the same audience/mood/product space
3. Second carousel with discovery/value/save intent
4. Next viral cinematic short

This creates three posts from one larger creative theme while limiting paid video generation.

## Non-negotiable production rules

- Social content must use purpose-built social campaign visuals rather than final website product imagery.
- Website imagery can be used only as product-truth reference or extraction source when needed.
- Real fragrance identity must remain recognizable.
- Do not publish generic/fantasy bottle substitutions.
- Viral/desire first; education is secondary and usually belongs in carousel copy/caption.
- Trend audio should be selected natively on TikTok/Instagram/YouTube when available.
- No generic synthetic transition SFX.
- Paid motion generation starts only after keyframes and shot plan pass visual review.
- 9/10+ = strong; 8–8.5/10 = usable/conditional; 7/10 = supporting content only; below 7 = reject/rebuild.
